**DrywallPro Master** es la plataforma profesional definitiva (Web + Móvil) para contratistas, instaladores de pladur, ingenieros, arquitectos y presupuestistas de sistemas constructivos en seco (*Drywall, Pladur, Cartón-Yeso, Cielos Rasos, Plafones y Steel Framing*).

Permite calcular de forma milimétrica los materiales necesarios según normas internacionales (**ASTM C840, EN 520, USG Gypsum Handbook**), generar presupuestos oficiales en PDF para clientes, emitir órdenes de compra para almacén, y visualizar en planos **2D y 3D interactivos** la modulación estructural de parantes, canales, lana acústica y fijaciones.

## 🌟 Características Principales (Top 1 Features)

### 1. 📐 10+ Tipologías Constructivas Estandarizadas
* **Techo ST (Estándar):** Cielo raso continuo suspendido con perfiles primarios a 1.20m y omegas a 40.7cm.
* **Techo RH (Resistente a Humedad):** Placa verde hidrófuga con tornillería zincada y sellado antihongos para baños y cocinas.
* **Muro Sencillo (Una cara / Trasdosado):** Revestimiento directo o semidirecto sobre muros existentes de ladrillo u hormigón.
* **Tabique Divisor (Dos caras - Acústico):** Pared autoportante doble placa con lana de vidrio/roca en el interior.
* **Muro RF (Resistente al Fuego - FRL 60/120):** Placas rosas de 15mm, masilla intumescente y lana de roca para vías de evacuación.
* **Plafón Reticulado Suspendido (60×60 / 2×2 ft):** Rejilla vista T24 (perfil principal 3.66m, secundarios y terciarios) y baldosas acústicas minerales.
* **Cajillo / Viga / Cortinero Drywall:** Quiebros, vigas falsas con iluminación indirecta LED y refuerzos de esquina.
* **Fachada EIFS (Exterior):** Placas OSB/Cementicias, barrera Tyvek, EPS 50mm, malla de fibra de vidrio y Base Coat.
* **Steel Framing Estructural:** Perfiles portantes PGC y soleras PGU calibre 20 (0.90mm) con cruces de San Andrés.
* **Proyecto Multi-Partes:** Cómputo unificado para múltiples habitaciones simultáneas.

### 2. 🎮 Visualizador Técnico Estructural 2D & 3D Interactivo
* **Modo 3D Isométrico:** Corte constructivo por capas en tiempo real mostrando perfiles metálicos, relleno de lana mineral, placas de yeso biseladas y patrón de atornillado.
* **Modo 2D Plano Técnico:** Vista ortogonal con líneas de cota, distanciamiento entre ejes de montantes y replanteo de aberturas.
* **Control de Capas (Layers):** Activa o desactiva a voluntad: *[Perfiles]*, *[Placas]*, *[Aislamiento]*, *[Tornillos]*, *[Cotas]*.
* **Zoom & Inclinación:** Controles dinámicos para inspección técnica en reuniones con clientes o encargados de obra.

### 3. 🚪 Gestor Multi-Estancias con Deducción de Aberturas
* Agrega tantas estancias como tenga tu obra (*Salón, Dormitorio 1, Baño Principal, Pasillo, etc.*).
* Deducción automática del metrado de **puertas y ventanas**, añadiendo a la vez los refuerzos estructurales de dintel y jambas.
* Plantillas de 1-Clic: Presets preconfigurados para iniciar presupuestos en segundos.

### 4. 💰 Cotizador Financiero & Lista de Compras Inteligente
* **Precios Editables & Multimoneda:** Soporte nativo para USD ($), EUR (€), MXN ($), COP ($), ARS ($), CLP ($) y PEN (S/.).
* **Cálculo de Embalajes Comerciales:** Convierte automáticamente metros lineales y m² a unidades de compra reales (*Placas completas, tiras de perfil de 3m, cajas de 1,000 tornillos, baldes de masilla de 28kg, rollos de cinta de 150m*).
* **Gestión de Stock en Almacén:** Ingresa las existencias disponibles en tu bodega para deducir la **Orden de Compra Faltante**.
* **Mano de Obra & Margen:** Modos de mano de obra por m²/sqft o importe fijo, porcentaje de beneficio operativo del contratista e impuestos (IVA).

### 5. 📄 Exportación Profesional en 1 Clic
* **Presupuesto Técnico Oficial en PDF:** Formato formal con datos de tu empresa, cliente, desglose de materiales, mano de obra, plazos de validez, condiciones generales y campo para firmas.
* **Orden de Compra en PDF:** Documento limpio enfocado en despacho de insumos para el proveedor de materiales o encargado de almacén.
* **Exportación CSV / Excel:** Descarga inmediata de tablas compatibles con Microsoft Excel, Google Sheets y ERPs.
* **Respaldo JSON:** Guarda y restaura proyectos completos en archivos JSON locales.

### 6. 🌐 Sistema Dual de Medidas (Métrico & Imperial)
* Alterna entre metros (m, cm, m²) y pies/pulgadas (ft, in, sq ft) con un solo clic.

### 7. 📚 Asesoría Técnica & Normativa USG / Knauf
* Tabla de alturas máximas de tabiques según deflexión admisible (L/240 y L/360).
* Guía visual de **Niveles de Acabado de Juntas (Nivel 0 al Nivel 5)**.
* Solución a problemas frecuentes en obra: prevención de fisuras, distanciamiento de fijaciones y fijación sobre soleras.

## 🚀 Inicio Rápido (Web)

### Requisitos
* Node.js v18+ (probado en Node v20 y v22)
* npm v9+

### Instalación y Ejecución

```bash
# Clonar el repositorio
git clone https://github.com/yhquintero/DrywallMaterialsCalculator.git
cd DrywallMaterialsCalculator

# Iniciar la aplicación Web directamente desde la raíz
npm run dev
```

La aplicación se abrirá en `http://localhost:3000` (o el puerto configurado).

### Scripts Disponibles

| Comando | Descripción |
| :--- | :--- |
| `npm run dev` | Inicia el servidor de desarrollo Vite con HMR y acceso en red local |
| `npm run build` | Compila TypeScript y genera el bundle de producción en `web/dist` |
| `npm run preview` | Previsualiza localmente el build de producción |
| `npm run test:web` | Ejecuta la suite de pruebas unitarias con **Vitest** |

## 🔐 Consola Web de Licencias (Keygen Centralizado)

Plataforma profesional, **HTTPS por diseño**, para controlar el keygen de las dos apps
(`:app` DrywallPro Master y `:keygen` Android) desde un solo lugar.

```bash
npm run install:all     # instala web/ y server/
cp server/.env.example server/.env   # completa JWT_SECRET y MASTER_KEY

npm run dev:https       # API https://localhost:8443 + consola https://localhost:3000/admin
# o sin TLS local: npm run dev  (web) + npm run dev:api (API)
```

Accede a **`/admin`** en la web. Al primer arranque el servidor crea el usuario administrador
(`BOOTSTRAP_ADMIN_*` del `.env`, o una contraseña aleatoria que imprime **una sola vez**) y
genera un par **RSA-4096 por app**.

| Capacidad | Detalle |
| :-- | :-- |
| **Inicio de sesión con roles** | JWT 30 min en memoria + refresh `httpOnly`/`Secure`/`SameSite=Strict`, bcrypt-12, bloqueo tras 5 intentos |
| **RBAC** | 5 roles (ADMIN, MANAGER, OPERATOR, AUDITOR, CLIENT) y **27 permisos** granulares + overrides `allow`/`deny` por usuario |
| **Firma en el servidor** | Emite el mismo `LicenseInfo` que el keygen Android (`SHA256withRSA`), con llave privada cifrada AES-256-GCM |
| **Ciclo de vida** | Emitir, renovar (encadenado), cobrar, revocar, lista negra y bloqueo de dispositivos |
| **Estadísticas** | Ingresos por app/plan/moneda, licencias activas y vencidas, dispositivos únicos |
| **Tasas de cambio** | Publicación manual + histórico; mismo contrato que consume el scraper de las apps |
| **Auditoría** | Cada acción sensible con actor, IP, User-Agent, severidad y exportación CSV |
| **Endpoints públicos** | `/.well-known/*` (claves PEM/JSON y apps) y `/api/public/*` (salud, tasas, revocación, validación) |

La compatibilidad con las apps es total: `RemoteKeyProvider` descarga la clave pública desde
tu consola en lugar de un dominio ajeno, y el keygen puede subir sus licencias emitidas con
`ConsoleSync`. Si `LICENSE_CONSOLE_URL` queda vacío, las apps siguen funcionando offline.

* [`server/README.md`](server/README.md) — API, RBAC, contrato de firma, tests.
* [`docs/HTTPS_Y_DESPLIEGUE.md`](docs/HTTPS_Y_DESPLIEGUE.md) — TLS en desarrollo, Docker + Caddy, nginx, Vercel/Netlify, integración Android y lista de verificación.

## 📐 Fórmulas y Consumos Estandarizados

Los consumos base por m² incorporan un coeficiente de desperdicio técnico estándar del 8% al 10% (configurable):

$$\text{Planchas} = \text{Área Neta} \times \left(\frac{1}{\text{Área Placa}}\right) \times (1 + \text{Merma})$$

$$\text{Perfiles Primarios (m)} = \text{Área Neta} \times 0.85 \times (1 + \text{Merma})$$

$$\text{Perfiles Omega (m)} = \text{Área Neta} \times 1.10 \times (1 + \text{Merma})$$

$$\text{Tornillos Placa T2} = \text{Área Neta} \times 24 \text{ uds/m}^2$$

$$\text{Masilla de Juntas (kg)} = \text{Área Neta} \times 0.90 \text{ kg/m}^2$$
